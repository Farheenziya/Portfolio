# Farheen Ziya F — Portfolio

A static portfolio site: one `index.html` with HTML, CSS and JavaScript inside. No framework, no build step, no environment variables.

## Run locally
Double-click `index.html`, or run `python3 -m http.server 8000` in this folder and open http://localhost:8000

## Deploy
Vercel / Netlify / GitHub Pages: leave the build command empty and publish the repo root.
